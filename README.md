# EMIPredict AI

EMI eligibility classification (Eligible, High_Risk, Not_Eligible) aur maximum safe monthly EMI regression, with MLflow tracking and a Streamlit app.

## Run locally
pip install -r requirements.txt
streamlit run app/app.py

## Dataset
Dataset file repository mein nahi hai (size ki wajah se). Retrain ke liye emi_prediction_dataset.csv project folder mein rakhein.
